================================================================================
                          DATABASE SCHEMA CHANGES
================================================================================

REMOVED TABLE: rentals_wallet
  Columns removed:
    - id (BigAutoField)
    - user_id (OneToOneField) 
    - balance (DecimalField)
    - created_at (DateTimeField)
    - updated_at (DateTimeField)

CREATED TABLE: rentals_payment
  New columns:
    - id (BigAutoField - PK)
    - user_id (ForeignKey to auth_user)
    - payment_provider (CharField) - 'stripe', 'paypal', etc.
    - external_payment_id (CharField, UNIQUE) - Provider's transaction ID
    - amount (DecimalField 12,2)
    - currency (CharField, default='NGN')
    - status (CharField) - pending, completed, failed, cancelled
    - payment_method (CharField) - card, bank_transfer, mobile_money
    - description (TextField)
    - related_property_id (ForeignKey to rentals_property, nullable)
    - related_rental_id (ForeignKey to rentals_propertyrental, nullable)
    - metadata (JSONField) - Custom provider data
    - created_at (DateTimeField, auto_now_add)
    - updated_at (DateTimeField, auto_now)
    - paid_at (DateTimeField, nullable) - When payment confirmed
  
  Indexes added:
    - PRIMARY KEY on id
    - FOREIGN KEY on user_id
    - UNIQUE KEY on external_payment_id
    - INDEX on status
    - INDEX on created_at

MODIFIED TABLE: rentals_transaction
  Removed:
    - wallet_id (ForeignKey) - NO LONGER EXISTS
  
  Added:
    - user_id (ForeignKey to auth_user) - NOW DIRECT USER REFERENCE
    - payment_id (ForeignKey to rentals_payment, nullable)
    - status (CharField, default='completed')
  
  Updated:
    - payment_id is nullable for manual/legacy transactions
    - user_id is required (no default)

MIGRATION: 0003_remove_wallet_add_payment.py
  Operations:
    1. DROP TABLE rentals_wallet
    2. CREATE TABLE rentals_payment
    3. ALTER TABLE rentals_transaction
    4. ADD COLUMN user_id
    5. ADD COLUMN payment_id
    6. ADD COLUMN status
    7. REMOVE COLUMN wallet_id

Running Migration:
  $ python manage.py migrate rentals 0003_remove_wallet_add_payment
  or
  $ python manage.py migrate

⚠️  IMPORTANT: BACKUP YOUR DATABASE BEFORE RUNNING MIGRATION!

  └── Relationships: owner (FK User)

  ├── Status: UNCHANGED
